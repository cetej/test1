## Available Skills

### /last30days [topic]
Live prompt research tool. Scans Reddit, X/Twitter, and community forums from the last 30 days on any topic, then generates a structured, deployment-ready prompt based on what the community has actually figured out.

**Examples:**
- `/last30days prompting techniques for ChatGPT for legal questions`
- `/last30days Midjourney techniques from Discord this week`
- `/last30days Cursor rules that actually work in 2026`
- `/last30days Claude prompting patterns from builders shipping real products`
- `/last30days Suno music generation best prompts`
- `/last30days code generation prompt engineering latest`
